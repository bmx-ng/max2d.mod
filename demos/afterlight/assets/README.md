# Afterlight artwork

`greenhouse.png` was generated with the built-in image-generation tool for this
demo on 2026-11-20. It is embedded by `afterlight.bmx` and appears on the title
and ending screens. Gameplay tiles, plants, robot and machinery are drawn by
BlitzMax code. The original generated PNG is retained without edits.

## Generation prompt

Use case: stylized-concept. Asset type: background illustration for a small native
puzzle game, Afterlight. Create a polished painterly 16:9 landscape illustration
of an abandoned glass greenhouse at blue hour, with a tiny cream-coloured rounded
maintenance robot and a magnificent dormant tree in a circular mechanical
planter. Deep ink blue, muted teal foliage, small amber energy lights, delicate
glass roof ribs, atmospheric botanical science fiction. Wide composition: tree
and robot mostly in right half, left half dark and quiet for separately rendered
game title/menu. Cozy, hopeful, beautifully crafted indie game cover art, subtle
grain, strong silhouette shapes. No text, letters, logos, UI or watermark. This
is decorative title and ending art, not a sprite sheet.
