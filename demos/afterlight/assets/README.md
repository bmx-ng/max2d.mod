# Afterlight artwork

`greenhouse.png` is an AI-generated background illustration embedded by
`afterlight.bmx` for the title and ending screens. It has no baked-in title or
interface text; the darker left side leaves room for the game menu. The PNG is
bundled unchanged and needs no image-generation tool at build or runtime.

Gameplay tiles, plants, the robot and machinery are drawn by BlitzMax code.
To replace the cover art, retain the filename and 16:9 composition, or update the
embedded image reference and placement in `afterlight.bmx`.
