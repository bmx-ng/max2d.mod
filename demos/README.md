# Max2D demos

Complete, small applications that combine the modules in an interactive setting.

- [Afterlight](afterlight/README.md): a quiet three-room greenhouse puzzle with
  keyboard/touch controls, tilemaps, cached effects and generated cover artwork.
- [Flux Pinball](pinball/README.md): a Box2D physics table with motorised flippers,
  charged launches, Forge/Frenzy/Multiball challenges, an Overdrive finale,
  cached and animated effects, synthesized audio, and independent touch controls.

- [Reactor Workshop](reactor_workshop/README.md): reusable scene components with
  independent animation, cached bloom, shared artwork and live update counters.

- [Touch Playground](touch_playground/README.md): simultaneous scene drags, native
  SDL3 touch conversion, pointer capture and cancellation experiments.

- [Camera World](camera_world/README.md): a scrolling chart, fixed interactive HUD,
  cached relays, camera-aware picking and an immediate-mode minimap.

- [ECS Swarm](ecs_swarm/README.md): Flecs simulation with retained scene views,
  bounded spawning, entity expiry and explicit ownership. Requires `Ecs.Flecs`.

- [Below the Light](below_the_light/README.md): a scrolling submarine exploration
  scene with projected headlights, normal-mapped rocks, occluder shadows, bloom,
  sonar and mouse/touch steering.

Focused demonstrations of individual APIs remain in `examples/`.
