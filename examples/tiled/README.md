Original Max2D demonstration map and procedural tiles, under the repository zlib/libpng licence. Water animation and terrain/solid properties are authored in TSX.

The transformation maps use an original asymmetric arrow with coloured corners. Rectangular rows show None/H/V/HV, then D/DH/DV/DHV. Hex rows show 0/60/120/180 degrees, with None/H/V/HV across each row.
