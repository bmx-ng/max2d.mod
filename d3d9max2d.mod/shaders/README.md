# D3D9 drawing shaders

`draw.hlsl` implements ordinary ps_2_0 drawing. `float.hlsl` adds a ps_3_0 copy
path for floating-point sources or destinations, with explicit bilinear point taps.
Both receive full-precision tint through TEXCOORD1. The float path uses
TEXCOORD2 screen positions and VPOS to correct pixel-centre interpolation. The fixed-function vertex
pipeline supplies position and texture coordinates; no vertex shader is required.

Regenerate on Windows with the SDK MinGW directory on PATH:

```
bmk makeapp -r -o compile_draw compile.bmx
compile_draw.exe draw.hlsl float.hlsl ../draw_shader.cpp
```

The BlitzMax build tool needs D3DCompiler. Applications use embedded bytecode and
do not load a compiler DLL. Commit shader source and generated bytecode together.
