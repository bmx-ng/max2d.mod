# D3D9 drawing shader

`draw.hlsl` implements the same straight/premultiplied-alpha conversion as the
OpenGL backend. The committed `../draw_shader.cpp` contains ps_2_0 bytecode;
applications do not link to or load a shader compiler.

To regenerate on Windows, with the SDK MinGW bin directory on PATH:

```
g++ -static compile.cpp -o compile.exe -ld3dcompiler
compile.exe draw.hlsl ../draw_shader.cpp
```

The build tool needs Microsoft's D3DCompiler DLL. Commit both the shader source
and generated bytecode when changing the shader. The generated file is imported
as a separate compilation unit so BMK rebuilds it when the bytecode changes.
